# Job-Salary-Prediction
CareerWorth — A machine learning web app that predicts job salaries using Linear Regression, trained on 250K+ job records. Built with Python, Flask, and scikit-learn by Team Insight Coders.  If you need something even shorter for a character-limited field:  Job salary prediction web app using Linear Regression (Flask + scikit-learn).

The project was built to solve a common problem: job seekers often don't know what salary to expect for a role, and recruiters need a quick way to estimate a fair salary for a given profile. Instead of relying on manual guesswork or inconsistent sources, SalaryIQ uses a Linear Regression model trained on 250,000 job records to generate an instant, data-driven salary estimate.

The website has four sections — a home page introducing the project, a prediction page where users enter their details and get an estimated salary, a dashboard showing dataset insights and model performance, and an about page with project and team information.

This is a mini-project built by Team Insight Coders, Department of Artificial Intelligence and Data Science.
